# Security Policy

## Supported Branch

Security fixes are accepted for the `main` branch.

## Reporting A Vulnerability

Do not open a public issue for security problems.

Report vulnerabilities privately to the maintainer:

```txt
GitHub: @Ujjwal92425
Repository: Ujjwal92425/PostgreSQL
```

Include:

- A clear description of the issue
- Steps to reproduce
- Affected files or routes
- Expected impact
- Suggested fix, if known

## Security Expectations

- Do not commit secrets, tokens, passwords, private keys, database URLs, or `.env` files.
- Do not add dependencies unless they are needed.
- Do not bypass CI checks.
- Do not push directly to `main` unless you are `Ujjwal92425`.
- Do not weaken branch protection, CODEOWNERS, or workflow permissions.

## Maintainer Response

The maintainer will review reports, validate impact, and apply fixes through a private branch or pull request as appropriate.
